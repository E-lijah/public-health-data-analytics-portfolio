# Mental Wellbeing Analysis Using IBM SPSS

## Project Overview
This project investigates factors associated with mental wellbeing using survey data collected from 496 respondents. The analysis was conducted using IBM SPSS and Microsoft Excel.

## Research Objective
To identify factors associated with mental wellbeing by applying statistical analysis techniques and interpreting the findings.

## Software Used
IBM SPSS Statistics
Microsoft Excel
Statistical Analyses Performed
Data Cleaning
Descriptive Statistics
Frequency Analysis
Reliability Analysis (Cronbach's Alpha)
Pearson Correlation Analysis
Multiple Linear Regression

## Skills Demonstrated
Data preparation
Statistical analysis
Data interpretation
Research reporting
Public health data analysis

Completed. Further interpretation and visualisation will be added as the portfolio develops.
